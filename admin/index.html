Configuración pendiente

El panel necesita una cuenta de Supabase (gratuita) para guardar fotos, vídeos, la carta y los mensajes. Todavía no está conectada, así que no se puede subir nada.

  1. Crea un proyecto en supabase.com.
  2. En SQL Editor, ejecuta supabase/01_schema.sql (y opcionalmente 02_carta_inicial.sql).
  3. En Authentication → Users, crea tu usuario y ejecuta supabase/03_crear_admin.sql con tu email.
  4. Copia la Project URL y la anon public key (Project Settings → API) en assets/js/config.js y vuelve a publicar.

Los pasos detallados están en el README del proyecto.
